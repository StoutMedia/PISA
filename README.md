# PISA Website

A responsive static marketing website for PISA, focused on education insights and student support planning.

## Available scripts

- `npm run build` — copies the static site into `dist/` for deployment.
- `npm run serve` — serves the built site locally from `dist/` on port 4173.
- `npm run clean` — removes the generated `dist/` directory.

## Project structure

- `index.html` — page content and semantic structure.
- `styles.css` — responsive layout, visual system, and component styling.
- `script.js` — mobile navigation and dynamic footer year.
- `scripts/build.mjs` — build script for producing the deployable `dist/` folder.
